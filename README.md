
# GitHub Actions Hands-On Activity

This repository demonstrates basic GitHub Actions workflows and event triggers.

## Workflows

- **Hello GitHub Actions:** Runs manually using `workflow_dispatch`.
- **Workflow Triggers Demo:** Runs on pushes and pull requests to the `main` and `dev` branches.
- **Scheduled Workflow Demo:** Configured to run every 5 minutes using a cron schedule.
- **Repository Dispatch Demo:** Responds to the `custom-event` repository dispatch event.

## Purpose

This activity demonstrates how to configure, trigger, and monitor GitHub Actions workflows.
